# Roadmap

## v0.1 - application baseline

- dependency-free CLI;
- draft schemas;
- deterministic matching;
- freshness-aware evidence;
- redaction and fingerprints;
- four service profiles;
- NixOS publication module baseline;
- tests and CI.

## Funded v1.0 target

- reviewed capability and requirement specifications;
- typed units, extension namespaces and conformance rules;
- safe NixOS collector and evidence plugins;
- public/private disclosure compiler;
- HTTP discovery and caching profile;
- production matcher library and CLI;
- conformance suite and four maintained service profiles;
- integration examples for schedulers and hosting control planes;
- independent security review;
- WCAG-aware documentation;
- standards submission package for the discovery location and media type where appropriate.
