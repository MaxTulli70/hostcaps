# Security policy

HostCaps is an early baseline. Do not publish private topology, credentials, secrets, internal addresses or unique hardware identifiers.

Please report vulnerabilities privately to **maxtulli@onmake.it** with the subject `HostCaps security report`. Include affected version, reproduction steps and impact. ONMAKE will acknowledge valid reports and coordinate disclosure.

The project will not design new cryptographic primitives. Future integrity signatures will use established formats and implementations.
